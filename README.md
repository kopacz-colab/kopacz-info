# KOPACZ

KOPACZ is a private application created for managing products and sales offers on the owner's Allegro account.

## Purpose

The application integrates with the Allegro REST API to:

- search and identify products in the Allegro Product Catalog,
- create and manage sales offers,
- create or submit product data when a product is not yet available in the Allegro Product Catalog,
- read sales settings required for creating valid offers,
- automate selected product and offer management processes.

KOPACZ is developed for private use and is not offered as a public service.

## Allegro REST API

KOPACZ uses the official Allegro REST API and OAuth 2.0 authorization.

Current application version: **0.1.0**

## Security

Authentication credentials, access tokens, refresh tokens, customer data and other confidential information are not stored in this public repository.

This repository contains public information about the KOPACZ application only.
